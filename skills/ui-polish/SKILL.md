# ui-polish

Read the nearest AGENTS.md and the project's design file first; where they differ from the files below, they win. Read PRODUCT.md too when it exists.

Follow [polish](references/impeccable/reference/polish.md). For app UI, dashboards, admin and tools,
also read [operate](references/impeccable/reference/operate.md). Read
[craft-floor](references/impeccable/reference/craft-floor.md) immediately before any UI edit.
