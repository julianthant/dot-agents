  Use this skill when fixes for an existing screen or area need planning before anyone builds them:
  it audits the surface against its own design evidence, confirms the real UI problems and
  design-system drift, and writes self-contained implementation plans another agent can carry out,
  without editing product code. Use it for "audit the Settings screen" or "plan the cleanup of this
  area". Not for reviewing a change (ui-review), critique while working (ui-critique) or making
  fixes (ui-polish).
