# ui-redesign

Read the nearest AGENTS.md and the project's design file first; where they differ from the files below, they win. Read PRODUCT.md too when it exists.

Follow the reference for the problem; combine them when several apply:

- too safe or bland: [bolder](references/impeccable/reference/bolder.md)
- too loud or busy: [quieter](references/impeccable/reference/quieter.md)
- too complex: [distill](references/impeccable/reference/distill.md)
- spacing, rhythm or hierarchy: [layout](references/impeccable/reference/layout.md)
- type hierarchy or fonts: [typeset](references/impeccable/reference/typeset.md)

Read [craft-floor](references/impeccable/reference/craft-floor.md) immediately before any UI edit.

Skip every `scripts/impeccable` command and every link to an impeccable file this skill does not ship
(`new-work.md`, `live.md`, `ios.md`, `android.md`). A whole new visual world is ui-dashboard or
ui-direction work.
