## Install

Installation requires an explicit request naming the source. Do not infer a package from a similar
name.

- A skill folder from a named source goes into `~/.agents/skills/` with its license and provenance,
  then follows [links](links.md).
- A plugin stays in the owning agent's plugin system; installing or enabling it needs its own
  explicit authorization.
- After installation, classify exposure and dependencies before claiming the menu is simplified.
